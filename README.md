# 美食探索+ | AI美食助手 🍜🤖

> **"用AI的智慧，探索城市的美味"**

欢迎来到美食探索+！这不是一个普通的地图应用,而是一个集成了AI智能助手的美食探索平台。想象一下，当你在一个陌生的城市，不知道去哪里吃饭时，只需要问问AI助手，它就能根据你的位置、口味偏好、预算范围，甚至是饮食限制，为你推荐最合适的餐厅，还能帮你规划一条完美的美食探索路线。这就是我们想要实现的体验！

## 🎯 这到底是个什么东西？

简单来说，美食探索+让你能够：
- **智能美食搜索**：基于高德地图API，精准搜索附近的美食餐厅
- **AI美食助手**：内置智能对话系统，像朋友一样和你聊美食
- **个性化推荐**：根据你的口味、预算、饮食习惯推荐餐厅
- **美食路线规划**：AI帮你规划完美的美食探索路线
- **社区分享**：分享你的美食体验，看看别人的推荐
- **收藏管理**：收藏你喜欢的餐厅，随时查看

比如说，你可以这样问AI助手：
- "附近有什么好吃的火锅店？"
- "推荐几家距离我500米内的咖啡厅"
- "帮我规划一个3小时的美食路线"
- "有什么适合带孩子去的餐厅？"

AI助手会根据你的问题，自动调用地图搜索功能，分析附近的餐厅，然后给你最合适的建议。它甚至能考虑到你的饮食限制（比如素食、无麸质等），为你筛选出最合适的选择。

## 🎮 使用体验

想象你正在北京旅游，中午想找个地方吃饭，但不知道去哪里。你打开美食探索+，点击右下角的AI助手按钮：

**你**："附近有什么好吃的川菜馆？"

**AI助手**："让我帮你搜索一下附近的川菜馆..."

几秒钟后，地图上出现了多个标记点，列表中显示了附近的川菜餐厅，包括距离、地址等信息。

**AI助手**："我为你找到了10家附近的川菜馆。其中'川香居'距离您只有500米，评分4.5星，人均消费80元，是个不错的选择。"

你点击"川香居"，查看详细信息，觉得不错，点击导航按钮，高德地图自动打开，为你规划路线。

或者，你想来一次美食探索之旅：

**你**："帮我规划一个3小时的美食路线，包括小吃、甜点和咖啡"

**AI助手**："好的，让我为你规划一条美食探索路线..."

AI助手会自动搜索附近的小吃店、甜点店和咖啡馆，然后规划一条合理的路线，在地图上显示出来，并在路线引导面板中列出所有停靠点。你可以一键开始导航，开启美食之旅！

## 📋 快速开始

### 环境要求
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 网络连接（用于加载地图和调用AI API）

### 使用步骤

1. **下载项目**
```bash
# 克隆或下载项目文件
git clone <your-repo-url>
cd food-explorer
```

2. **配置API密钥**
打开 `index.html`，找到以下位置并替换为你自己的API密钥：

```javascript
// 高德地图API配置（第10-14行）
window._AMapSecurityConfig = {
    securityJsCode: '你的安全密钥',
}

// 地图API加载（第14行）
<script src="https://webapi.amap.com/maps?v=2.0&key=你的地图密钥&plugin=..."></script>

// DeepSeek API配置（第2710行）
'Authorization': `Bearer 你的DeepSeek-API密钥`
```

3. **打开应用**
直接在浏览器中打开 `index.html` 文件即可使用。

### API密钥获取

**高德地图API**：
1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册并创建应用
3. 获取 Web 服务 Key 和安全密钥

**DeepSeek API**：
1. 访问 [DeepSeek](https://platform.deepseek.com/)
2. 注册并获取API密钥
3. 将密钥替换到代码中

## 🎨 功能详解

### AI助手功能

AI助手是本项目的核心功能，它能够：

**理解自然语言**：
- "附近有什么好吃的？" → 搜索附近所有美食
- "我想吃火锅" → 搜索附近火锅店
- "推荐几家距离我500米内的咖啡厅" → 按距离和类型筛选
- "有什么适合素食的餐厅？" → 考虑饮食限制

**智能推荐**：
- 基于位置推荐最近的餐厅
- 根据偏好筛选餐厅类型
- 考虑饮食限制（素食、清真等）
- 根据预算范围推荐
- 根据用餐时间推荐（早餐、午餐、晚餐、夜宵）

**路线规划**：
- 规划包含多个美食点的路线
- 优化路线顺序，减少绕路
- 计算总距离和预计时间
- 支持不同交通方式（步行、驾车、公交）

### 地图功能

**定位功能**：
- IP自动定位到当前城市
- GPS精准定位到当前位置
- 支持15个主要城市快速切换

**搜索功能**：
- 关键词搜索（如"火锅"、"咖啡"）
- 分类浏览（快餐、中餐、西餐等）
- 周边搜索（搜索指定位置附近的餐厅）
- 滚动加载更多结果

**信息展示**：
- 餐厅名称、地址、类型
- 模拟评分和人均消费
- 地图标记和信息窗口
- 收藏、导航、分享快捷操作

### 分享功能

**发布分享**：
- 选择餐厅
- 上传照片
- 撰写评价
- 设置评分

**浏览分享**：
- 查看当前城市的分享
- 按时间排序
- 点赞和评论（评论功能待开发）

### 收藏功能

## 🤔 为什么要做这个项目？

美食探索是每个人生活中的重要部分，但在陌生的地方找到合适的餐厅并不容易。传统的地图应用虽然能搜索餐厅，但缺乏智能推荐和个性化服务。

这个项目的灵感来源于：
1. **实际需求**：在陌生城市旅游时，常常不知道去哪里吃饭
2. **AI技术**：大语言模型的发展让智能对话成为可能
3. **用户体验**：希望让找餐厅变得简单、有趣

**技术是手段，体验是目的。** 这个项目不是为了展示技术，而是为了真正解决"吃什么"、"去哪吃"这个日常问题。
